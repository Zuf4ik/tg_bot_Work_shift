# Work Shift Tracker Bot

Telegram-бот для учёта рабочих смен, расчёта заработной платы и анализа доходов. Разработан на Go с использованием PostgreSQL.

## Возможности

- Добавление, редактирование и удаление рабочих смен.
- Настройка индивидуальной почасовой ставки.
- Автоматический расчёт отработанных часов и заработной платы.
- Учёт перерывов.
- Расчёт вечерних и ночных надбавок.
- Учёт дополнительных работ: разгрузка, мусор, доставка.
- Расчёт премий в зависимости от отработанных часов и месячной нормы.
- Просмотр истории смен с переключением месяцев.
- Расчёт заработанного и прогнозируемого дохода за выбранный период.
- Защита от пересечения рабочих смен.
- Проверка вводимых данных.
- Интерактивный календарь смен с переключением месяцев.
- Отображение рабочих дней в календаре.
- Просмотр смен за выбранную дату.
- Добавление смены непосредственно из календаря.
- Отображение отработанных часов и заработка за месяц.
- Разделение фактического и прогнозируемого дохода.


## Календарь смен

Бот предоставляет интерактивный календарь для удобного
просмотра рабочих смен и заработка.

### Возможности календаря

- Переключение между месяцами.
- Отметка дат с записанными сменами символом 🔹.
- Просмотр смен при выборе конкретной даты.
- Отображение времени, продолжительности, перерывов и оплаты.
- Добавление новой смены с автоматически выбранной датой.
- Подсчёт отработанных часов и заработка за месяц.

### Месячная статистика

Календарь автоматически рассчитывает:

- Общее количество отработанных часов.
- Основную заработную плату.
- Вечерние и ночные надбавки.
- Дополнительные выплаты за выполненные работы.

В месячную статистику включаются только завершённые смены.
Будущие смены отмечаются в календаре, но не учитываются
в фактически заработанной сумме.

Месячные премии в статистику календаря пока не включены.

### Часовые пояса

Для обработки времени используется часовой пояс
`Asia/Yekaterinburg` (UTC+5).

Время сохраняется в PostgreSQL с использованием
типа `TIMESTAMPTZ`.


## Безопасность REST API

REST API использует авторизацию через API-ключ.

### Механизм авторизации

Для защиты HTTP-запросов используется Middleware `apiKeyAuth()`.

Клиент должен передавать заголовок:

Authorization: Bearer <API_KEY>

Если ключ отсутствует или неверен, сервер возвращает:

401 Unauthorized

### Настройка

API-ключ передаётся через переменную окружения `API_KEY`.

Пример конфигурации:

API_KEY=your_secret_key

Секретные данные не должны храниться в репозитории.

### Сетевые ограничения

По умолчанию API слушает адрес:

127.0.0.1:8080

Это ограничивает прямой доступ к серверу локальными
подключениями.

Для безопасного подключения к API на VPS можно
использовать SSH-туннель.

### Ограничения

Текущая авторизация использует один общий API-ключ.

API-ключ не устанавливает личность отдельного
Telegram-пользователя и не проверяет принадлежность
смен конкретному пользователю.

Для публичного многопользовательского API потребуется
дополнительная аутентификация и проверка прав доступа.

## Архитектура

Проект разделён на несколько основных компонентов:

- `cmd/bot` — точка входа Telegram-бота.
- `cmd/api` — точка входа HTTP API.
- `internal/bot` — обработчики сообщений, кнопок и пользовательских сценариев.
- `internal/repository` — взаимодействие с базой данных.
- `internal/database` — подключение к PostgreSQL.
- `service` — бизнес-логика и расчёты.
- `model` — модели данных.
- `config` — конфигурация приложения.

## Расчёт заработной платы

Бот рассчитывает заработок на основе продолжительности смены, почасовой ставки и применимых надбавок.

Поддерживаются:

- Вечерние часы (22:00–00:00): +20%.
- Ночные часы (00:00–07:00): +30%.
- Дополнительная разгрузка: оплата двух часов.
- Вынос мусора: оплата 15 минут.
- Доставка: дополнительная выплата в размере половины базовой оплаты смены.

Дополнительные работы увеличивают заработок, но не изменяют количество фактически отработанных часов.



## Тестирование

Проект использует стандартный пакет Go `testing`.

Автоматические тесты проверяют:

- Расчёт продолжительности рабочих смен.
- Расчёт основной заработной платы.
- Вечерние и ночные надбавки.
- Дополнительные выплаты за разгрузку и доставку.
- Обработку времени в часовом поясе `Asia/Yekaterinburg`.
- Проверку авторизации REST API.
- Расчёт месячной статистики календаря.
- Исключение будущих смен из фактического заработка.
- Исключение смен, не относящихся к выбранному месяцу.

### Запуск всех тестов

```bash
go test ./...
```

### Запуск тестов без использования кеша

```bash
go test -count=1 ./...
```

### Подробный вывод результатов

```bash
go test -v ./...
```

### Тестирование календаря

```bash
go test ./internal/bot -run TestSumCalendarMonthTotals -v
```

### Подход к тестированию

Бизнес-логика расчёта зарплаты отделена от работы
с базой данных.

Для тестирования месячной статистики используется
Dependency Injection: вместо реального обращения
к PostgreSQL в тест передаётся функция, возвращающая
подготовленные данные.

Это позволяет проверять расчёты без подключения
к внешним сервисам.
